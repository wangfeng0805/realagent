## 宠物公约：进入范围与基本要求

GATE M 西岸梦中心 **室外开放区域**可携带宠物进入，但 **上海市禁养犬、异宠除外**。宠物须由成年人牵绳入场。大型犬标准为 **肩高超过35厘米或体重超过30千克**，大型犬须佩戴嘴套。携带人须妥善处理宠物排泄物，并遵守《上海养犬管理条例》相关规定。来源图片：`e7c2491a998b8f11619635295c13e867.jpeg`。

## 宠物公约：看护、电梯与责任

宠物主人须看管好宠物，避免影响他人，不得放任或驱使宠物做出恐吓、攻击他人的举动。宠物打架、扑人等过激行为发生时，主人须及时分开宠物；宠物伤人或宠物受伤等事件由宠物主人自行负责。

严禁宠物直接在自动扶梯上行走；需要乘坐自动扶梯时，应将宠物抱起或放入宠物背包。请勿让宠物单独进入厢式电梯；乘梯时主人应收紧牵引绳，避免绳缠绕或阻挡电梯门。若宠物在轿厢内过于兴奋或吠叫，应及时安抚并控制，以免影响他人。
