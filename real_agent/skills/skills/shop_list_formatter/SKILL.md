# Shop List Formatter

## 适用场景

用户问"有哪些店铺/商户/店/某品类店"等需要**列出多家店铺**的场景。

## 输出形式（权威实现）

店铺列表由代码确定性渲染，输出 ```shops 代码块，前端渲染成图文卡片：

```shops
{"total": 144, "shops": [{"name": "店铺名", "logo": "https://img.antank.cn/...", "category": "零售", "location": "1栋 · 102A", "hours": "营业时间暂未收录"}]}
```

- 由 `app/agent/response_formatter.py` 的 `render_merchant_list` 生成；前端 `renderShops`（`web/app.js`）+ `.shop-*`（`web/style.css`）负责渲染。
- `total` 为门店总数，`shops` 为本次返回的若干家（默认 8）。**头部说明与「查看更多」折叠由前端自动渲染，正文不要再自己写「共有 N 家…」这句**，否则会和前端头部重复。
- 本 Skill 为规范说明；LLM 需要手动排店铺列表时，也应遵循下列要求，不要退回大 Logo / 表格 / 冗长要点。

## 排版要求（最终呈现，由 renderShops 实现）

1. **卡片为一行三段**：左侧 60px 方形 Logo（浅灰底、`object-fit: contain`）；中间店铺名（主体）+ 类目小圆角标签 + 营业时间（带时钟图标）；右侧定位（红色定位图标 + 楼栋位置）+ 右箭头 `›`。
2. **店铺名是视觉主体**，Logo 为辅助，不占大块空间、不做焦点、不用大图、不用竖线表格。
3. **展示策略**：默认展示前 **4 家**，其余折叠在「查看更多 N 家」按钮里，点击展开。
4. **自然中文、不暴露字段名**：位置写 `1栋 · 102A`（不含 `#`）；营业时间缺失写「营业时间暂未收录」。
5. **头部**：门店图标 + `西岸梦中心共有 N 家店铺，先给您看前 M 家：`，其中数量用品牌紫色高亮（由前端渲染，正文不写）。
